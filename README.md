# ExonUI Plugins, Extensions, Install Links & Templates

Ready-to-install agent bundles built on `@exonui/grid`, `exonui` CLI, and `skills/` v1.

| Agent | Bundle / Template | Quick install |
|---|---|---|
| **Claude Code** | [`claude-code/`](./claude-code) + [`.claude-plugin/marketplace.json`](./.claude-plugin/marketplace.json) | `claude plugin marketplace add ./plugins && claude plugin install exonui@exonui` |
| **Gemini CLI** | [`gemini-cli/`](./gemini-cli) | `gemini extensions link ./plugins/gemini-cli` |
| **Cursor** | [`cursor/`](./cursor) | [Add to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=exonui&config=eyJjb21tYW5kIjoibnB4IiwiYXJncyI6WyIteSIsImV4b251aUBsYXRlc3QiLCJncmlkIl19) |
| **VS Code** | [`vscode/`](./vscode) | [Add to VS Code](vscode:mcp/install?%7B%22name%22%3A%22exonui%22%2C%22type%22%3A%22stdio%22%2C%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22exonui%40latest%22%2C%22grid%22%5D%7D) |
| **Codex** | [`codex/`](./codex) (`config.toml` + `AGENTS.md`) | `codex mcp add exonui -- npx -y exonui@latest grid` |
| **OpenCode** | [`opencode/`](./opencode) (`opencode.json` + `AGENTS.md`) | `opencode mcp add exonui -- npx -y exonui@latest grid` |

Or configure any supported agent in one command:

```bash
npx -y exonui@latest init
```

Machine-readable deeplinks, CLI commands, and snippets live in [`install-links.json`](./install-links.json) (generated by `pnpm plugins:sync` from `packages/catalog/src/grid-links.ts`).
